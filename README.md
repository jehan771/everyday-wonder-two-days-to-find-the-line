## About

A single sentence, at most 200 characters, on a small moment of wonder in everyday life — judged pairwise by an AI judge that rewards surprise. The program writes one text to `/output/entry.txt`:

> The automatic door opened for the wind before it opened for me, and for a second the shop thought the weather was a customer.

## Run

```sh
node main.ts
```

Node 22 or later. No dependencies, no network, no secrets.
